# FlowDesk — Gerenciador de Projetos e Tarefas

O **FlowDesk** é uma aplicação web de gerenciamento de projetos e tarefas desenvolvida ao longo das aulas de **Programação Web II**. Inspirado em ferramentas como Trello e Linear, o projeto simula um produto SaaS e evolui progressivamente, aplicando conceitos e boas práticas do desenvolvimento web moderno.

## Objetivo

Construir uma aplicação realista, organizada e escalável, utilizando tecnologias do ecossistema React e práticas próximas às encontradas no desenvolvimento profissional de software.

## Funcionalidades planejadas

- 📋 **Quadro Kanban:** organização de tarefas por status.
- 🧩 **Componentização:** criação de componentes reutilizáveis com React.
- 🔄 **Props e estado:** comunicação entre componentes e atualização dinâmica da interface.
- 🧭 **Navegação:** organização das páginas e rotas da aplicação.
- 🔌 **Integração com API:** comunicação com um backend para persistência de dados.
- 🔐 **Autenticação:** gerenciamento de acesso e usuários.
- 🧪 **Testes:** validação do comportamento dos componentes e funcionalidades.
- 🐳 **Docker:** preparação do ambiente de desenvolvimento e execução da aplicação.
- 🚀 **Deploy:** publicação do projeto para acesso online.

As funcionalidades serão implementadas gradualmente durante o desenvolvimento do projeto.

## Tecnologias

- React
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- Git e GitHub
- Docker *(etapa planejada)*

## Como executar

Certifique-se de ter o Node.js e o npm instalados.

```bash
git clone <URL_DO_REPOSITORIO>
cd flowdesk
npm install
npm run dev
```

O Vite exibirá no terminal o endereço local para acessar a aplicação no navegador.

## Projeto educacional e portfólio

O FlowDesk é desenvolvido de forma incremental, acompanhando a evolução dos conteúdos da disciplina. Cada etapa adiciona novas funcionalidades e consolida conhecimentos de arquitetura de interfaces, reutilização de componentes, organização de código e desenvolvimento de aplicações web.

O objetivo final é construir uma aplicação demonstrável, documentada e que possa ser aprimorada pelos estudantes como parte de seu portfólio profissional.
